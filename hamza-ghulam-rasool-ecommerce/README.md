# Hamza Ghulam Rasool Store — E-Commerce Website

A standalone responsive e-commerce UI/UX project built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. Recommended: install the **Live Server** VS Code extension and click **Go Live**.
5. No backend or Node.js is required.

## Included
- Home
- Shop / search / sorting / category filtering
- Product details
- Categories
- Deals
- Cart with quantity controls
- Wishlist with localStorage
- Checkout
- Order success
- Login / Register demo flows
- Profile
- Orders
- Order tracking
- About
- Contact
- FAQ
- 404
- Responsive Bootstrap UI
- Toasts, modal quick view, product data and localStorage cart/wishlist

## Notes
This is a frontend/demo e-commerce project. Payment processing, real authentication, database, courier APIs and admin backend are not connected.
